# Design and code
Create a modern, premium, responsive design matching the brand and assets.
Keep code readable, maintainable, accessible, secure, and performant.

Use a colocated CSS Module for each styled TSX component/page.
Read globals.css before styling, reuse its variables, and set the
default body background there.
Follow `docs/VISUAL_SYSTEM.md` for shared visual tokens, fluid layout,
media treatments, and keyed content records.
No UI libraries or additional dependencies without approval.

Authorize privileged operations and keep secrets server-side.
