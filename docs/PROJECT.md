# Project
Build [VETRA STORE] for [Selling premium product].
Goal: [Online selling, Retail and Wholesale].
VETRA STORE is a retailer for multiple products and brands. ESHAN is one
product brand; it does not define the store. Store pages and shared navigation
must remain suitable for the wider assortment, while product pages identify
their own brands and facts.
Required features: [All feature for online selling products and each product have their own static page with their own design and structure].
Choose appropriate pages and navigation within this scope.

Stack: Next.js App Router, TypeScript, MongoDB for application data,
Cloudinary for media, and Vercel as the deployment target.
